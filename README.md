# audio-echo-cancel

## 题面

视频会议开回声消除后，对方声音反而越来越大、还带金属回音：延迟估计把互相关峰值的窗索引直接当延迟，整体偏移半个窗长；参考信号对齐时补零方向写反，参考被提前而不是延后；NLMS 更新没有按参考能量归一化，参考一响步长就发散；权重更新符号取反，误差越大权重反而把回声推高；回声估计没有乘滤波器权重，输出恒为 0；ERLE 用线性能量比而不是 dB，10 倍抑制被记成 10 而不是 20；双讲检测只看误差能量、不跟麦克风能量作比较，远端单讲也被误判；参数入口不校验，`mu=3` 直接参与更新导致发散；批量处理让所有通道共用一份权重，通道之间互相串音；`length<=0` 不拦截，更新时除以零。aec/nlms.py 是核心，tests/test_nlms.py 15个红。要修的是：用互相关峰值的真实滞后代替窗索引；按延迟在参考前补零并在尾部截断；按参考能量归一化并钳制步长；沿误差下降方向更新权重；用权重与参考的内积估计回声；按 dB 计算 ERLE；同时比较麦克风与误差能量并只在双讲时暂停自适应；在入口统一校验长度和步长；为每个通道维护独立权重；非法参数先整体拒绝且不产生半批结果。

## 运行

在仓库根目录执行：

```bash
python -m pytest tests -q
```

初始状态应恰好为 `15 failed`，不允许出现 collection error、import error 或 syntax error。实现目标是让全部 15 条测试通过。
